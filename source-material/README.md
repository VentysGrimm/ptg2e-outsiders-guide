# Source Material

Put the Outsiders Guide PDF here:

```text
source-material/Outsiders_Guide.pdf
```

This folder is local-only. It is for source PDFs, extracted text, cached images, source maps, and temporary parsing output.

Recommended cache locations:

- `source-material/.cache/text/`
- `source-material/.cache/images/`
- `source-material/.cache/source-index.json`

Do not move book PDFs or raw extracted source files into module release folders.
